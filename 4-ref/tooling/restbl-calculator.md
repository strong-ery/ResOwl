# RESTBL Calculator

Mind's RESTBL Calculator generates a [[restbl]] for a mod, containing every vanilla entry plus your modified and added ones. (confirmed)

## Setup

Download it from [GameBanana](https://gamebanana.com/tools/24830).

## Usage

1. Open the tool and select your mod folder through the file picker.
2. It detects the game automatically.
3. Click **Generate**.

The output is written to the proper System/Resource/ path inside of your mods romfs automatically.

None found so far.
