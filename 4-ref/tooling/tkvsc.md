# TKVSC

TKVSC is the editor tool for [[byml]] files, developed and maintained by the team behind this project. It supports multiple ModuleSystem games, most recently including OOT. (confirmed)

## Setup

- [totk-vscode](https://github.com/BladesawStudios/totk-vscode) is the tool itself.
- [tkvsc-addons](https://github.com/BladesawStudios/tkvsc-addons) holds the OOT-specific support.

## Usage

TKVSC has its own [guide](https://tkvsc.dev/docs/index.html).
